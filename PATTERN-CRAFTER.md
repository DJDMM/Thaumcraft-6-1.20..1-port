# Шаблонный верстак и диоптра

Правила переноса Thaumcraft6.1.BETA26 на Minecraft1.20.1/Forge47.4.10.
Документ описывает реализацию0.36.0; результаты фактически завершённых
проверок публикуются в [VALIDATION.md](VALIDATION.md).

## Открытие и изготовление

Шаблонный верстак требует завершённой диоптры. Диоптра открывается после
базовой артефакторики, открытия Sensus/Auram и16 единиц сырых наблюдений
ауромантии. Затем открытие Fabrico и по32 единицы сырой теории големостроения,
артефакторики и ауромантии позволяют изучить шаблонный верстак.
Каждое из двух исследований даёт исходные5+5XP за начало и завершение.

Оба устройства изготавливаются на магическом верстаке, по50vis каждое.
Диоптра требует кристаллы Aer/Aqua, пять блоков магического камня,
две железные пластины, резонатор и таумометр. Шаблонный верстак требует
Terra/Aqua/Ordo, резонатор, воронку, два простых механизма, обычный верстак
и доску великого дерева. Точная раскладка доступна в обычном Таумономиконе.

## Диоптра

Прибор показывает сетку13×13 чанков вокруг себя; центр сетки соответствует
его собственному чанку. Высота каждой точки равна количеству выбранной
ауры, делённому на500 и умноженному на64, с усечением и пределом64.
Обновление происходит раз в20 тиков. Щелчок переключает Vis и Flux;
сигнал красного камня режим не меняет. Прибор не расходует ауру.

Компаратор показывает центральную точку: при нуле выдаёт0, иначе
floor(высота/64×14)+1. Поэтому полная шкала даёт15. Как в оригинале,
смена режима не обновляет измерения до следующего двадцатого тика.
Недоступные чанки показываются нулём; прибор не загружает их ради измерения.
Сохраняются выбранный режим и169 значений сетки.

## Автоматический крафт

Верстак получает материалы из инвентаря сверху через его нижнюю сторону,
а результат кладёт в инвентарь снизу через верхнюю. Внутренних предметных
слотов и отдельного GUI у него нет. Маленький регулятор на корпусе
переключает десять исходных схем. Обычный щелчок по остальной части
корпуса не переключает схему.

| Схема | Раскладка одинакового материала |
| --- | --- |
| 0 | Все девять клеток |
| 1 | Одна клетка |
| 2 | Две по горизонтали |
| 3 | Две по вертикали |
| 4 | Квадрат2×2 |
| 5 | Три по горизонтали |
| 6 | Три по вертикали |
| 7 | Прямоугольник3×2 |
| 8 | Прямоугольник2×3 |
| 9 | Кольцо из восьми клеток |

Наличие схемы само по себе не создаёт рецепт: проверяется настоящее
совпадение обычного рецепта крафта. Подходящие материалы выбираются
в порядке слотов верхнего инвентаря. Исходные правила эквивалентности
OreDictionary перенесены через ограниченные современные теги и точное
сравнение предмета, повреждения и NBT; детали приведены в аудите ядра.

Проверка крафта идёт раз в20 тиков. При пустом запасе устройство сначала
забирает до5vis, даже если рядом ещё нет подходящих инвентарей или рецепта.
Успешный крафт расходует1vis. Дробный положительный остаток меньше1,
который не позволяет ни крафтить, ни пополниться, сохранён как особенность
выпущенной BETA26. Красный камень останавливает рабочие попытки.

Выход должен вместить результат и возвращаемые ёмкости. Современная
проверка резервирует их общую вместимость и сохраняет физическое владение
оплаченными предметами при повторных вызовах и отменённых появлениях.
Неизвестные сторонние обработчики без наблюдаемого владения не считаются
совместимыми автоматически. При удалении устройство возвращается обычным
предметом; хранящийся vis не превращается в бесплатное переносимое топливо.
